# 01 · 产品设计

## 1. 一句话

一个只做「每天一份」的 iOS 新闻简报。列表看日期和标题，点进去是编号短讯。读的时候在标题后点「感兴趣」或「不感兴趣」，系统据此识别标签；「我的」里能看见这些标签，也可以再改。之后的简报按这份偏好来。

暂用名：**日简**。上架前可以改名。

## 2. 给谁用

第一阶段只有你自己：装到自己的 iPhone 上读，确认顺手后再考虑 App Store。

因此第一版：

- 不注册、不登录、不做账号体系
- 昵称和偏好只存在这台手机上
- 历史简报按日期保留，可回看

## 3. 和参考页、热搜的关系

参考页是喷嚏网的「图卦」：一天一篇，标题形如 `【喷嚏图卦20261008】口出狂言`，正文用 `【1】【2】【3】` 串起当天若干条。

本产品的阅读节奏与它相同。第一版的内容就来自当天这期图卦：编号、短语标题和条目正文都从那里来，不再混入各平台热搜。

| 参考页 | 本产品 |
| --- | --- |
| 一天一篇 | 一天一份简报 |
| 短标题概括当天 | 同样：日期 + 一句短标题 |
| 编号条目，有长有短 | 每条标题、第一句摘要；查看详情里是这一条更完整的正文 |
| 文中多图 | 列表卡片一张当日小图；详情以文字为主，头图沿用这张小图 |
| 网站栏目很多 | App 只有两个 Tab |
| 读者只阅读 | 每条标题后可点感兴趣或不感兴趣 |

免责声明、打赏、站点导航、全文检索不纳入。

## 4. 信息架构

底部两个 Tab，没有第三层主导航。

```text
日简
├── 每日简报
│   ├── 简报列表（日期、标题、当日小图）
│   └── 简报详情
│       └── 每条标题后：感兴趣 / 不感兴趣
└── 我的
    ├── 基础信息（昵称）
    ├── 感兴趣的标签（系统识别，可手动改）
    └── 不感兴趣的标签（系统识别，可手动改）
```

兴趣的主路径在简报详情里。「我的」是识别结果的查看和修正，打开 App 时不必先去勾选。

## 5. 第一版做什么

- 简报列表：新的在上，每行日期、标题、一句导语、右侧小图
- 简报详情：当天标题 + 编号短讯；每条标题后有「感兴趣」「不感兴趣」
- 点选之后，按该条的主题和领域更新本机偏好，并在「我的」里显示
- 「我的」：改昵称；查看两组标签；删除、移动到另一组、从词表或短词手动添加
- 每天抓取喷嚏图卦，整理成一份简报（时区：上海）
- 偏好只影响下一份尚未生成的简报，不改写旧日期

## 6. 第一版不做什么

- 账号、云同步、多设备
- 评论、点赞、打赏
- 推送通知
- 搜索、收藏夹
- 在手机上抓网站
- App Store 上架材料

这些留到你真机用过、决定买开发者会员之后再排。

## 7. 成功标准（你自己试用）

- 打开 App，三秒内看到最近几天的简报列表
- 点进一份，能在几分钟内读完
- 对一条新闻点「不感兴趣」后，「我的」里出现对应标签；下一天同类主题不再占你的关注
- 对一条新闻点「感兴趣」后，下一天相关主题更靠前
- 简报就是当天那期图卦：短语标题、编号条目、来源能对上原文
- 全程在 Windows 上开发和预览，不依赖自己买 Mac
