# 06 · 实现说明

对应第二稿。确认前的设计文没有改规则，这里只记代码落在哪。

| 部分 | 位置 |
| --- | --- |
| 网页预览：列表、详情、标题下的感兴趣 / 不感兴趣、「我的」 | `mobile/` |
| 同一套界面的 Flutter 实现，供 Codemagic 编 iOS | `flutter_app/` |
| Codemagic 工作流 | 仓库根目录 `codemagic.yaml` |
| 兴趣记分、领域 3 次才出现、下一份怎么选 | `mobile/src/shared/`，Flutter 侧在 `flutter_app/lib/logic.dart` |
| 内置的最近几期图卦 | `mobile/src/data/tugua-library.json` 与 `flutter_app/assets/tugua-library.json`，由整理程序一起写入 |
| 只抓喷嚏图卦、按编号定稿 | `collector/` |
| 手机拉取简报、同步兴趣 | Vercel：`/api/library`、`/api/preferences`、`/tugua/`。本机 `8787` 仍是同一套接口 |

热搜抓取函数还在 `collector/src/sources.ts`，第一版的整理不会调用它们。

列表摘要是图卦条目的第一句。查看详情使用这一条更完整的正文。来源名和这一期图卦的链接保留。

试用顺序：先 `mobile` 里 `npm run web` 看效果；确认后再改 `flutter_app/`，需要独立安装包时用 Codemagic 编 iOS。抓新图卦时在 `collector` 里 `npm run collect`，然后把仓库推上去，由 Vercel 发布。手机在「我的」填 Vercel 地址后下拉刷新。
