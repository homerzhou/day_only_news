# 04 · 技术方案与真机安装

约束：开发机是 Windows，没有 Mac；还没有 Apple Developer Program（每年 99 美元）会员。希望先装到自己的 iPhone，用着好再买会员。

## 1. 结论

日常开发和在自己手机上阅读，用 **Expo（React Native）+ iPhone 上的免费 App「Expo Go」**。这条路不买 Mac，也不买开发者会员。

自己的电脑无法单独完成 iOS 安装包编译。真正要一个独立图标、不依赖 Expo Go 的 App 时，编译交给云端 Mac，安装仍可在 Windows 上完成。买会员之前，独立包大约每 7 天要装一次。

```text
现在（0 元会员，0 台 Mac）
  Windows 写代码 → 手机 Expo Go 扫码 → 在真机上读简报

你觉得值得留下之后
  云端 Mac 打出安装包 → Windows 用 Sideloadly + 免费 Apple ID 装到手机
  （约 7 天需重装一次）

决定公开给别人用
  购买 Apple Developer Program → TestFlight → App Store
```

## 2. 为什么是 Expo，而不是先租一台 Mac 写 Swift

这个 App 的界面是列表、详情、标签和本地保存，都在 Expo 自带能力里：导航、图片、本机存储、打开系统浏览器。用 Expo Go 预览时，不需要自己的签名证书。

SwiftUI 更贴 iOS，但写和编译都要 Xcode，Xcode 只在 macOS 上。没有自己的 Mac 时，每一轮改界面都要进远程 Mac，试用阶段会更慢。

如果以后要上架，同一套 Expo 工程可以交给云端 Mac 出 iOS 包，不必推倒重写。

## 3. 阶段 A · 现在就能装到自己手机

条件：

- Windows 安装 Node.js
- iPhone 从 App Store 安装 **Expo Go**（苹果提供的通用壳，免费 Apple ID 即可下载）
- 手机和电脑在同一 Wi-Fi，或使用 Expo 的隧道连接

用法：电脑运行开发服务，Expo Go 扫码打开「日简」。改完界面，手机上即看到。感兴趣 / 不感兴趣和识别出的标签存在手机本地。

限制（试用阶段可接受）：

- 桌面上的图标是 Expo Go，不是「日简」自己的图标。打开后进入日简
- 离开开发服务时，已打开过的内容仍可看；要拉新简报需要服务或以后的正式接口
- 不能用这项方式发给朋友安装

这一阶段用来确认设计和阅读手感，符合「先体验，好再买会员」。

## 4. 阶段 B · 不想开着电脑时，仍不买会员

目标：主屏幕上是日简自己的图标。

步骤：

1. 用云端 Mac 编译未签名或可再签名的 iOS 安装包。可选：
   - [Codemagic](https://codemagic.io) 或 GitHub Actions 的 macOS 构建机（按分钟，适合偶尔打一次包）
   - 按小时租 Mac：MacinCloud、MacStadium 等。AWS 的 Mac 实例按 24 小时起租，偶尔打一次包偏贵
2. 在 Windows 用 [Sideloadly](https://sideloadly.io) ，登录你自己的免费 Apple ID，把包装到这台 iPhone。手机用数据线连上电脑，并在 iPhone 上信任这台电脑。

免费 Apple ID 的系统限制：

- 描述文件大约 **7 天**后失效，App 打不开，需要再用 Sideloadly 装一次
- 同时存在的这类个人签名 App 数量很少（通常按 3 个以内安排）
- 没有推送通知。日简第一版本来也不做推送

云端 Mac 在这一步是编译机，不是你的开发主机。代码仍然在 Windows 上写。

## 5. 阶段 C · 体验好了再买会员

Apple Developer Program，99 美元 / 年。买了之后：

- 用 TestFlight 安装，包的有效期按测试周期算，不再是 7 天
- 可以装到几台自己的设备，也可以小范围给别人测
- 再往后才是 App Store 上架（隐私说明、账号外删除如果将来有账号、截图、审核）

买会员仍然不必须买 Mac。签名和上传可以继续放在 Codemagic / EAS 这类云端 Mac。

## 6. 和设计对应的工程边界（确认后再建）

| 部分 | 第一版放哪 |
| --- | --- |
| 列表、详情、标题后的感兴趣 / 不感兴趣、「我的」 | 手机 App |
| 昵称、点选记录、识别出的标签、已读简报缓存 | 手机本地 |
| 图卦条目、摘要、当日 JSON | Windows 上的整理。手机不抓网站 |
| 账号服务器 | 不做 |

整理程序和 App 分开。试用时电脑开着整理结果，手机经同一 Wi-Fi 读取当天 JSON。Expo Go 离开电脑后，已经打开过的简报仍留在手机上。

确认后的开发顺序：

1. 两个 Tab、详情里的两个点选、样例简报能读完
2. 点选写入本机，「我的」显示出主题和领域，并支持删除、移动、手动添加
3. Windows 整理程序：当天图卦 → 按编号写成简报 → 按偏好筛掉不感兴趣 → 写出 JSON
4. App 改为读取整理结果，你用 Expo Go 通读几天
5. 云端打包留到你说「要独立图标」的时候

## 7. 费用对照（试用期）
