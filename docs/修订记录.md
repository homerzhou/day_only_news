# 修订记录

每轮确认前的设计都留在这里。现行方案以各篇正文为准，本文件只记「改了什么、为什么」。

## 2026-10-10 图片本地保存，详情按图卦段落展示

图卦图片在浏览器里打不开。整理时把每一条里的图下载到本地，列表封面和详情都用这份本地图。查看详情不再把正文压成一段，而是按图卦里这一条的段落和图片顺序排开。

## 2026-10-10 第一版只用来自喷嚏图卦

你的意见：内容第一版完全来自喷嚏图卦。

相对此前「热搜 + 图卦一起合成」的改动：

| 处 | 此前 | 现在 |
| --- | --- | --- |
| 材料 | 各平台热搜和图卦合并 | 只读喷嚏图卦。热搜代码先留着，不进入简报 |
| 一条新闻 | 热搜词改写成短讯 | 图卦编号条目本身：列表用第一句，查看详情用这一条的正文 |
| 顺序和标题 | 按热度重排，标题另写 | 按图卦编号。当天标题用图卦标题里那句短语 |
| 日期 | 抓取当天没有图卦时，可能套到别的一期 | 日期取自标题里的 `喷嚏图卦YYYYMMDD`。这一期还没发，就不做这一天 |
| 定稿 | 21:30 把热搜快照定稿 | 这一期图卦一旦抓到就定稿。已定稿的图卦日期不再改写 |

兴趣规则没改：不感兴趣仍只影响下一份还没定稿的日期。

## 2026-10-09 实现中的调整

读简报时的「感兴趣 / 不感兴趣」改为标题右侧的两个图标，点选规则不变。每条短讯下面增加「查看详情」，从底部弹出更完整的一段；列表上的摘要仍保持短。

## 2026-10-09 第二稿

你的意见：在「我的」里先选兴趣不合适；每条新闻标题后放「感兴趣」「不感兴趣」；点了之后系统自己识别，并在「我的」里能看到、也能再改；新闻要去各家网站抓，用各平台热搜做输入，并结合喷嚏图卦。

相对第一稿的改动：

| 处 | 第一稿 | 第二稿 |
| --- | --- | --- |
| 兴趣从哪来 | 打开「我的」，在 12 个词里多选 | 读简报时点标题后的「感兴趣 / 不感兴趣」，系统把这条新闻上的标签记入偏好 |
| 「我的」 | 兴趣胶囊墙，是主操作 | 展示已识别的感兴趣、不感兴趣；可删除、移动、手动添加 |
| 标签粒度 | 只有 12 个领域 | 领域 + 主题。主题点一次就出现；领域要同一方向累计 3 次才出现，避免一条新闻带偏整个领域 |
| 材料 | 先用手工样例，抓取以后再说 | 第一版就抓取。输入是各平台热搜，加上当天喷嚏图卦里的事件 |
| 图卦 | 只借鉴版式和篇幅 | 版式仍借鉴；内容上把图卦当作当天事件线索，摘要用自己的话写，并链回公开报道 |

未改：两个 Tab、列表上的日期 / 短标题 / 小图、一天一份、改偏好不改写已生成的旧简报、Windows + Expo Go 试用、暂不买开发者会员。

## 2026-10-09 第一稿

初稿范围：两个 Tab；列表与短讯详情；在「我的」里手选 12 个兴趣标签；材料先用样例 JSON。已被第二稿替换，原文不再单独保留，差异见上表。
