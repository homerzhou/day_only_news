# 03 · 内容规格、兴趣识别、材料来源

## 1. 一份简报是什么

每个上海时区自然日一份。定稿之后不改写正文。

第一版的一天，就是当天那期喷嚏图卦。图卦标题里的日期是这份简报的日期。这一期还没发布，就不产出这一天。抓到之后即定稿，已定稿的日期不再改写。

一份简报包含：

| 字段 | 规则 |
| --- | --- |
| 日期 | `YYYY-MM-DD` |
| 标题 | 4–12 个汉字的短话，来自当天最重要的一条，气质如「口出狂言」 |
| 导语 | 一行，由前三条标题压缩 |
| 小图 | 头版报道的配图地址，或纯色占位 |
| 条目 | 见下 |
| 生成时间 | 记录何时写成，界面第一版不展示 |

## 2. 单条新闻

| 字段 | 规则 |
| --- | --- |
| 编号 | 从 1 连续 |
| 分组 | `今日要闻` 或 `你的关注`。尚无偏好时全部为今日要闻 |
| 标题 | 不超过 28 个汉字 |
| 摘要 | 80–120 个汉字：谁、发生了什么、一个关键数字或后果 |
| 领域 | 1–2 个，取自第 4 节词表。供识别和筛选，详情里不单独占一行 |
| 主题 | 1 个短词，2–12 字，来自热搜词或事件名，例如「诺贝尔化学奖」 |
| 来源名 | 媒体或机构名 |
| 原文链接 | 有则附上 |
| 热度来源 | 命中了哪些热搜、是否被当天图卦收录。界面第一版不展示，留给核对 |
| 是否头版 | 当天仅一条为真，供标题和小图使用 |

摘要是该编号条目的第一段，不超过 120 字。查看详情按图卦原文的段落和图片顺序展示这一条，图片在整理时下载到本地。来源写喷嚏图卦，链接打开这一期图卦。

条数：

- 还没有偏好：今日要闻 12 条
- 已有偏好：今日要闻 5 条 + 你的关注最多 10 条，合计不超过 15
- 同一事件只出现在一个分组。又热又命中兴趣时，放在今日要闻，你的关注补下一条

## 3. 标题后的点选如何变成标签

每条新闻在整理时已经带好领域和主题。用户点的是这一条，系统把这条上的标签记到偏好里。

记分：

- 点「感兴趣」：该条每个领域、以及主题，感兴趣次数 +1
- 点「不感兴趣」：同样这些标签，不感兴趣次数 +1
- 再点已选中的词：撤销，对应次数 −1
- 改点另一侧：先撤销，再按新的一侧 +1
- 同一条新闻只保留一种态度

什么时候出现在「我的」：

| 种类 | 出现条件 | 原因 |
| --- | --- | --- |
| 主题 | 某一侧次数不少于 1，且高于另一侧 | 点的就是这件事，一次就该看得见 |
| 领域 | 同一侧累计不少于 3 次，且高于另一侧 | 一条明星新闻不应把整个「文化」打进不感兴趣 |

净分为 0 时，该标签不出现在任一侧。

手动操作：

- 删除：次数清零，从列表消失
- 移动或手动添加：目标侧记 1 次，另一侧记 0，来源标为手动
- 之后在简报里再点到同一标签，继续加减。净分倒向另一侧时，标签会移到另一组，来源改回自动

## 5. 偏好如何影响下一份简报

生效点是下一份尚未定稿的简报。已定稿的日期保持原样。

还没有任何标签时：按公共热度输出 12 条今日要闻。

已有标签时：

1. 主题被标为不感兴趣：标题或事件名命中它的，不进入下一份简报。
2. 领域被标为不感兴趣：该领域的条目不进入「你的关注」。今日要闻里也跳过，只留一个例外：灾害、战争、重大伤亡、全国或全球性公共政策，若热度足够，仍可占今日要闻里的 1 条。
3. 主题被标为感兴趣：命中的事件优先进入「你的关注」。
4. 领域被标为感兴趣：在你的关注里按热度优先，不把未表态的领域全部挤掉。你的关注的 10 个位子里，至少留 3 个给「热度很高但你还没表态」的事件，避免简报只剩已经点过的那几类。
5. 当天标题用图卦标题里的短语。小图用这一期正文里的第一张图。封面表示这一天，不改成个人栏目名。

示例：点过三次科技类「感兴趣」，「科技」出现在感兴趣里；又对某演员的一条点了「不感兴趣」，主题「某演员」立刻出现在不感兴趣里，「文化」只记 1 次，先不出现。下一期还没定稿的图卦：某演员相关条目不收；领域被标成不感兴趣的，只留一条公共突发。

## 6. 材料从哪来

手机不抓网站。抓取和整理在 Windows 上跑，产出 JSON，App 只负责展示和保存偏好。

第一版只有一个来源：喷嚏图卦。各平台热搜不进入简报。

做法：

1. 打开图卦列表，读取最近几期。日期和短语都来自标题，例如 `【喷嚏图卦20261009】讨论最多的竟然是这个媒体真豁得出去`。列表第一期如果不是今天，就不用它冒充今天。
2. 按 `【1】【2】【3】` 拆成条目，保持编号顺序。太短的跳过。
3. 列表摘要用这一条的第一段。查看详情按原文段落和图片展示这一条，图片先下载到本地再显示。
4. 来源优先用条目里括号中的媒体名，没有就写喷嚏图卦。打开原文进入这一期图卦。
5. 给条目打 1–2 个领域和 1 个主题，供感兴趣 / 不感兴趣识别。
6. 还没有偏好时，整期按原顺序放进今日要闻。已有不感兴趣时，命中的主题去掉；命中的领域去掉，只留一条公共突发。已定稿的日期不再按新偏好改写。
7. 当天标题用短语（过长则截到 22 字）。小图用正文第一张图，没有图就用标题前两个字的色块。

图卦列表打不开时，不产出新的一天，已有日期仍可回看。
