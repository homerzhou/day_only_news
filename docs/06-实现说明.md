# 06 · 实现说明

对应第二稿。确认前的设计文没有改规则，这里只记代码落在哪。

| 部分 | 位置 |
| --- | --- |
| 列表、详情、标题下的感兴趣 / 不感兴趣、「我的」 | `mobile/` |
| 兴趣记分、领域 3 次才出现、下一份怎么选 | `mobile/src/shared/` |
| 内置的最近几期图卦 | `mobile/src/data/tugua-library.json`，由整理程序写入 |
| 只抓喷嚏图卦、按编号定稿 | `collector/` |
| 手机拉取简报、同步兴趣 | 整理程序的 `8787` 端口，`/api/library`、`/api/preferences` |

热搜抓取函数还在 `collector/src/sources.ts`，第一版的整理不会调用它们。

列表摘要是图卦条目的第一句。查看详情使用这一条更完整的正文。来源名和这一期图卦的链接保留。

试用顺序：先 `mobile` 里 `npm run web` 或 Expo Go 看样例；再 `collector` 里 `npm run collect` 和 `npm run serve`，在「我的」填电脑地址后下拉刷新。
